# mentHERship

Static website for mentHERship — a Best Talents Programme project connecting female university students in Kazakhstan with mentors from Switzerland.

## Edit
- Content: `index.html`
- Styles: `styles.css`
- Application form links and contact email: the `CONFIG` block at the top of `main.js`

## Preview locally
```
python3 -m http.server 8765
```

## Hosting
Served by GitHub Pages from the `main` branch. For the custom domain, add a `CNAME` file containing the domain and point DNS to GitHub Pages.
